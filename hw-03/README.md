Директорія домашнього завдання #3 для школи програмування 'Вивчай'
Створено для практикавання навичок роботи з Git та GitHub.
Містить каркас вебсайту.
Прогнано код через валідатор для уникнення логічних помилок.
В рамках виконання додаткового завдання було створено нову гілку feature/gitpages. У цій гілці було активовано gitpages, додано титульну сторінку репозиторію та впроваджено навігацію між сторінками репозиторію та домашніх завдань.
Для перегляду відкрити index.html (projects.html, about.html) у браузері або скористатись вкладеним нижче посиланням на багатосторінковий сайт (Github Pages), де відтворено структуру репозиторію (Репозиторій - домашнє завдання 3).
