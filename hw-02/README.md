Створено сторінку путівника для новачків в програмуванні.
Під час створення сторінки було відтворено структуру документу-прикладу.
У процесі використовувались набуті у останніх уроках навички (використання елементів виділення, таблиці, впорядковані і невпорядковані списки).
Прогнано код через валідатор для уникнення логічних помилок.
Для перегляду відкрити article.html в браузері або скористатись вкладеним нижче посиланням на багатосторінковий сайт (Github Pages), де відтворено структуру репозиторію (Репозиторій - домашнє завдання 2 - путівник для початківців).
