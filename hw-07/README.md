# Домашнє завдання №7 — Сторінка інтернет-магазину

Адаптивна сторінка магазину, створена за макетом у Figma та стилізована за допомогою CSS.

**Демо:** https://sandal01k.github.io/my-web-course/hw-07/index.html
**Макет:** [Figma](https://www.figma.com/design/YappZa894fTb1vxLR8OYWh/Free-eCommerce-Product-Cards--Community-?node-id=0-1&p=f&t=JMgqkkPiPSO0yuLC-0)

## Технології

- HTML5, CSS3
- Шрифт Roboto
- Flexbox (шапка, hero, каталог карток)
- Responsive Design

## Основні особливості

- Кольорова палітра з макету, доповнена контрастними кольорами для доступності
- Зображення експортовано з макету та оптимізовано
- Адаптивність:
  - десктоп — понад 896px (56rem)
  - планшети — до 896px (56rem): блок hero переходить у колонку
  - смартфони — до 600px (37.5rem): шапка в колонку, зменшені відступи
- Каталог товарів: кількість карток у ряду підбирається автоматично (`flex-wrap` і `flex-basis: 17rem`), окремі медіазапити для сітки не потрібні
- Ширина каталогу обмежена 76rem (1216px): на великих екранах не більше 4 карток у ряду, контейнер центрується
- Доступність: підписи для скрінрідерів (колір, рейтинг), підсвітка фокуса клавіатури (`:focus-visible`)

## Зміни після перевірки коду

- Кнопки «Купити» успадковують шрифт Roboto
- Рейтинг: зірки приховано від скрінрідерів, додано текст «Рейтинг 4 з 5»
- Неонова підсвітка тепер працює і при фокусі з клавіатури
- Каталог карток переведено з Grid на Flexbox (`flex-wrap`), додано обмеження ширини
- Значення брейкпоінтів у README приведено у відповідність до CSS

## Перевірка якості

- HTML перевірено через [W3C Validator](https://validator.w3.org/)
- Доступність перевірено через [WAVE](https://wave.webaim.org/) та Lighthouse
- Lighthouse: Accessibility 100%, Performance 99% (після оптимізації зображень)
