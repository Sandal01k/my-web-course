Домашнє завдання 1
Створено багатосторінковий сайт із трьох HTML-сторінок із використанням базової структури HTML.
Додано навігацію між сторінками.
Додано заголовки, текстові блоки, зображення та посилання.
Додано невпорядкований список.
Додано посилання на титульну сторінку репозиторію.
Прогнано код через валідатор для уникнення логічних помилок.
Для перегляду відкрити index.html (або about.html, contacts.html) у браузері або скористатись вкладеним нижче посиланням на багатосторінковий сайт (Github Pages), де відтворено структуру репозиторію (Репозиторій - домашнє завдання 1).
