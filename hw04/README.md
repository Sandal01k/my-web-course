У цьому уроці було налаштовано npm і prettier.
Було додано скрипт "prettier --write .", який активується командою "npm run format"
Було додано скрипт "prettier --check .", який активується командою "npm run format:check"
За допомогою скриптів було відформатовано документи в репозиторії. Зміни відмічено в комітах.
