Для виконання домашнього завдання 5 мною була обрана тема "Бібліотека ігор", а точніше "Souls-like ігри".
Саме ця тема мені досить близька, тому свій вибір зупинив на ній.
Формат сторінки - лендінг, метою якого є спонукання до придбання гайду для проходження гри.
Внесено правки відповідно до зауважень. Дещо змінено тему лендингу після першого варіанту на реалістичніший варіант.
Прибрано невикористані зображення з репозиторію. Банер-зображення з секції hero оптимізовано приблизно на 60%.
Сторінка перевірена через валідатор для уникнення логічних помилок.
Протестовано кінцевий варіант лендингу через Lighthouse. Результати такі: Accessibility 95%, Performance 99%. 5% доступності припали виключно на HTML-структуру документа (маленькі інтерактивні елементи для натискання пальцем на мобільному пристрої); 1% продуктивності - зображення-баннер.
Для перегляду відкрити index.html в браузері.
